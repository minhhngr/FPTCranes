- Interquartile Range (IQR)
- Quartile?
    - Quartile Formula
        - Q1 = (N + 1) * 1/4
        - Q2 = (N + 1) * 2/4
        - Q3 = (N + 1) * 3/4

- Constructing a Box Plot
  IQR = Q3 - Q1
  
- Determine Whiskers
  - Lower Fence =  Q1 - (1.5 * IQR)
  - Upper Fence = Q3 + (1.5 * IQR)
